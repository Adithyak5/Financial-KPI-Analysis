# Financial KPI Analysis

## Project Overview
This project analyzes startup financial performance using Excel, Python, Pandas, and Tableau.

## Objective
To analyze:
- Monthly Revenue
- Burn Rate
- Customer Acquisition Cost (CAC)
- Customer Lifetime Value (LTV)
- Run Rate

## Tools Used
- Excel
- Python (Pandas, Matplotlib)
- Tableau Public

## Project Deliverables
- Excel KPI Model
- Python Data Analysis
- Tableau Financial KPI Dashboard

## Dashboard
Created visualizations for:
- Revenue by Join Month
- Expenses by Join Month
- Marketing Cost vs Revenue
